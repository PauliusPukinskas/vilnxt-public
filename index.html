SVARBU TEISĖJAMS / IMPORTANT FOR JUDGES

Tik viešas projekto pristatymas.
Pagrindinis programinis kodas yra privatus.

Ši GitHub saugykla NĖRA visa VILNXT aplikacija. Joje pristatomas projektas ir pateikiami keli nedideli reprezentaciniai frontend pavyzdžiai. Didžioji dalis kodo, duomenų apdorojimas, backend sistemos, saugumo sprendimai, vidinės integracijos ir verslo logika lieka atskiroje privačioje saugykloje. Apie projekto apimtį spręskite pagal veikiantį produktą, ne pagal šios saugyklos dydį.

PUBLIC SHOWCASE ONLY. CORE SOURCE CODE IS PRIVATE. This repository contains a presentation and a few limited, non-sensitive frontend excerpts, not the production application. The majority of the source code and implementation remains private. Judges should evaluate the live product, not the quantity of code published here. The illustrative preview above does not display live events.
