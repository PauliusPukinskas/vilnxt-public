Ši GitHub saugykla NĖRA visa VILNXT aplikacija. Joje pristatomas projektas ir pateikiami keli nedideli reprezentaciniai frontend pavyzdžiai. Didžioji dalis kodo, duomenų apdorojimas, backend sistemos, saugumo sprendimai, vidinės integracijos ir verslo logika lieka atskiroje privačioje saugykloje. PUBLIC SHOWCASE ONLY. CORE SOURCE CODE IS PRIVATE. This repository contains a presentation and a few limited, non-sensitive frontend excerpts, not the production application.
